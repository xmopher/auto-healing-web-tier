# Auto-Healing Web Tier (AWS)

Terraform take-home: a self-healing, N+1 web tier behind a load balancer.

## Cloud choice

**AWS** — Auto Scaling Groups provide instance replacement out of the box, pair cleanly with an Application Load Balancer, and fit a low monthly budget (target ≤ AUD 20).
